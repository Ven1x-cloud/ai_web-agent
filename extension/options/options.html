1. Je eigen AI (lokaal en zelf te trainen)

Het brein van deze agent staat los van de extensie, in de map ai/ van deze repository. Dat is een echt, zelfgeschreven taalmodel dat jij traint op jouw eigen data — geen abonnement, geen daglimiet, en niets verlaat je computer.

Hoe start en train je het? (terminal, één keer)

Python 3.9 of nieuwer is genoeg; de enige afhankelijkheid is numpy.

cd ai
python -m pip install -r requirements.txt

python -m webai build            # eigen woordenboek leren uit ai/data
python -m webai train --preset tiny   # eerste model (minuten op een laptop)
python -m webai serve            # server op http://localhost:8787

Daarna werkt dit paneel meteen. Laat serve draaien zolang je de agent gebruikt.

Beter worden? Zet eigen tekst in ai/data/learned/ (.txt, .md of .jsonl met gesprekken) en train opnieuw. Of laat een cloudmodel voorbeelden maken met python -m webai distill en train dáárop — dat is de snelste manier om een klein eigen model bruikbaar te krijgen.

Wat mag je eigen AI?

Gereedschappen staan standaard uit bij het eigen model: de lijst met gereedschappen kost veel van de korte context, en een klein model maakt nog geen betrouwbare JSON-aanroepen. Zet het aan zodra je een groter model hebt getraind.

Een klein model heeft een korte context. Minder paginatekst = meer ruimte om te antwoorden.

2. Verbinding met een aanbieder

Liever een groot model uit de cloud (veel slimmer dan een klein eigen model)? Vul hier een sleutel in. OpenRouter heeft gratis modellen: account aanmaken, naar Keys, sleutel plakken. Zonder tegoed: 50 vragen per dag; met eenmalig $10 tegoed: 1000 per dag.

Voor Ollama: installeer Ollama, start het met OLLAMA_ORIGINS="chrome-extension://*" ollama serve en haal een model op (ollama pull gemma3:12b).

6. Wat mag de agent?

Elke stap is één verzoek aan het model. Bij gratis cloudmodellen tellen die mee voor de daglimiet (50). Minder tekens en stappen = goedkoper en sneller.

7. Reserve-aanbieders — nooit zonder antwoord

Is de hoofdaanbieder niet bereikbaar of is de daglimiet op, dan schakelt de agent automatisch over naar de eerstvolgende aanbieder hieronder. Het gesprek blijft gewoon bewaard, want dat zit in de extensie en niet bij de sleutel.

Handige combinatie: je eigen AI als hoofdaanbieder (onbeperkt, privé, zelf te trainen) en een cloudmodel als reserve voor de vragen waar je eigen model nog te klein voor is.

Let op: extra sleutels van hetzelfde OpenRouter-account geven géén extra vragen (de limiet geldt per account), en meerdere OpenRouter-accounts maken is verboden in hun voorwaarden. Voeg dus andere diensten toe. Voor deze accounts geldt meestal ook 18+ — vraag een ouder als je jonger bent.

8. Gegevens

Gesprekken worden alleen lokaal in je browser bewaard. Je API-sleutel blijft op dit apparaat. Feedback die je geeft met 👍 👎 ✏️ gaat alleen naar je eigen AI-server op localhost en wordt bewaard in ai/data/feedback.jsonl.

Hoe gebruik je de agent?

  • Klik op het icoon (of Ctrl+Shift+Y) → het zijpaneel opent naast de website.
  • Stel je vraag; de tekst van de pagina gaat automatisch mee. Zeg bijvoorbeeld: “Leg opgave 3 uit”, “Vertaal deze tekst”, “Wat staat er in de grafiek?”, “Zoek op wanneer dit gebeurd is”, “Vul mijn naam in bij het formulier”.
  • Selecteer tekst op een pagina → rechtermuisknop → “Vraag AI Web Agent”. Of rechtermuisknop op een afbeelding → “Afbeelding bekijken met AI Web Agent”.
  • Plak (Ctrl+V) of sleep een foto van je huiswerk in het paneel, of klik 📷 om een screenshot mee te sturen.
  • Wissel van tabblad: het paneel volgt automatisch de actieve website.
  • Vind je een antwoord goed of slecht? Gebruik 👍 👎 ✏️ — daarmee leer je je eigen AI bij.
